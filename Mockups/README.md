## 🎨 Design Tokens y Guía de Estilos Cromáticos

| Token UI | Código Hex | Uso en los Mockups |
| :--- | :--- | :--- |
| **Primary Brand** | `#0D9488` (Teal 600) | Botones primarios, logotipos, enlaces activos y acentos médicos. |
| **Primary Hover** | `#0F766E` (Teal 700) | Estados hover y focus de elementos clicables. |
| **Teal Light** | `#CCFBF1` (Teal 100) | Fondos de selección activa y badges médicos. |
| **Secondary Warmth** | `#F59E0B` (Amber 500) | Estrellas de calificación (4.9/5) y acentos cálidos de confianza. |
| **Emergency Red** | `#DC2626` (Red 600) | Cintillo y modal de Urgencias 24/7 y botón de llamada directa. |
| **Success Green** | `#16A34A` (Green 600) | Mensaje de confirmación de cita y validación de formulario. |
| **WhatsApp Brand** | `#25D366` | Botón oficial de confirmación y recordatorio automático. |
| **Text Primary** | `#0F172A` (Slate 900) | Titulares H1, H2, precios y textos de alto contraste. |
| **Text Secondary**| `#475569` (Slate 600) | Párrafos descriptivos, bajadas y etiquetas secundarias. |
| **Surface** | `#FFFFFF` | Fondo de tarjetas, modales e inputs de formulario. |
| **Canvas** | `#F8FAFC` (Slate 50) | Fondo general de la plataforma. |

## 📱 Accesibilidad y Grillas Aplicadas
* **Escritorio:** Frame `1440 x 1024 px` (Contenedor de 1200 px, 12 columnas, márgenes de 120 px, medianil de 24 px).
* **Móvil:** Frame `390 x 844 px` (4 columnas, márgenes de 16 px, medianil de 16 px).
* **Áreas Táctiles Mínimas (*Touch Targets*):** Mínimo `48 x 48 px` (WCAG 2.1 Nivel AA).
* **Tipografía Base:** Mínimo `16 px` en textos de lectura para adultos mayores (*Don Carlos*).

## 🚀 Cómo Usar Estos Archivos
1. **Para Entregar:** Comparte el archivo compilado `Mockups_Patitas_Felices.pdf`.
2. **Para Proyectar o Presentar:** Abre `Mockups_Patitas_Felices.html` en Chrome, Edge o Firefox.
3. **Para Revisar Pantallas Individuales:** Entra a las subcarpetas `Desktop/` o `Mobile/` y haz doble clic sobre cualquier pantalla.
